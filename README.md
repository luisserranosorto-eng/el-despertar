# El Despertar

Sismicidad en México y el mundo, en tiempo real, como el despertar de una bestia que vive debajo de todos nosotros.

Proyecto final de visualización de datos · Luis Eduardo Serrano Sorto

## Páginas
1. `index.html` · Portada
2. `bestia.html` · Escucha a la bestia (experiencia interactiva con datos en vivo)
3. `reflexion.html` · Reflexión final

## Archivos
- `css/estilos.css` · todos los estilos
- `js/main.js` · todo el código: datos en vivo, portada, bestia en 3D, sonido

## Datos
- U.S. Geological Survey, feeds GeoJSON en tiempo real (`all_day` cada minuto, `2.5_week` cada 5 minutos).
- Servicio Sismológico Nacional, UNAM (contexto y los tres 19 de septiembre).
- Mapas: Natural Earth.

La bestia en 3D usa three.js (cargado desde jsDelivr). Las fuentes vienen de Google Fonts.
